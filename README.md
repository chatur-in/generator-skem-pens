### Generator Formulir SKEM PENS

Aplikasi berbasis web statis yang digunakan untuk mempermudah mahasiswa Politeknik Elektronika Negeri Surabaya (PENS) dalam membuat, mempratinjau, dan mengunduh Formulir Klaim Poin SKEM (Satuan Kredit Kegiatan Mahasiswa) langsung menjadi dokumen cetak berformat PDF. 

### 🚀 Fitur Utama

* **Live Preview (Real-time):** Setiap perubahan data yang diisi pada kolom input akan langsung diperbarui secara instan pada visualisasi tata letak kertas formulir resmi.
* **Cetak PDF Presisi Tinggi:** Menggunakan konversi canvas ke dokumen dengan skala terbaik untuk menghasilkan file siap cetak di kertas ukuran A4.
* **Desain Responsif & Bersih:** Panel pengisian data yang adaptif untuk perangkat mobile maupun desktop, dilengkapi tampilan kop surat institusi formal.
* **Tanpa Backend:** Berjalan sepenuhnya di sisi klien (client-side), menjamin keamanan data pribadi mahasiswa karena tidak ada data yang disimpan di server luar.
